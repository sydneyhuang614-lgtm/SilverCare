# SilverCare 樂齡伴伴

SilverCare（樂齡伴伴）是一款為銀髮族與家人照顧者設計的健康陪伴 Web App。

> 一按就安心，需要時才多問一句。

本專案不要求長輩學習複雜操作，也不使用排名、連續打卡或責備式提醒。長輩可用一個按鈕完成平安報到；需要協助時，也能快速向家人表達需求。

## 主要功能

### 長輩端

- 一鍵平安報到與快速求助
- 「今天想休息」無壓力模式
- 用藥、血壓與伸展提醒
- 中文／台語介面及溫柔語音朗讀
- 可調整字體大小
- 「我看不懂」簡化協助模式
- 每日健康小知識與笑話
- 無倒數、無排行榜的懷舊配對遊戲
- 三項坐姿伸展圖解、10 秒倒數、聲音及震動提示

### 家人／照顧者端

- 查看平安報到、提醒進度與求助狀況
- 查看血壓、脈搏與歷史測量時間
- 連接支援標準 Bluetooth Blood Pressure Service 的血壓計
- 傳送簡短、溫和的關懷訊息

## 設計理念

- 正常時不打擾，需要時才提醒
- 大字體、大按鈕、高對比、少層級
- 尊重長輩自主，不把健康管理變成作業
- 健康資料只作日常紀錄，不提供醫療診斷
- 運動不以頁面停留時間計算，完成倒數才列入進度

## 開始使用

### 環境需求

- Node.js 22.13 或更新版本
- pnpm 或 npm

### 安裝與啟動

```bash
pnpm install
pnpm dev
```

開啟 `http://localhost:3000`。

### 建置

```bash
pnpm build
```

## 手機與藍牙說明

- 版面支援手機與電腦瀏覽器。
- Web Bluetooth 建議使用 Android Chrome 測試。
- iPhone Safari 對 Web Bluetooth 的支援有限。
- 部分血壓計使用原廠私有格式，需要額外的 API 或 SDK。
- 語音與震動效果依裝置及瀏覽器支援而定。

## 目前狀態

目前版本為學校專題的互動原型。登入、報到、提醒及血壓資料主要為前端展示；正式版本仍需串接帳號、資料庫、通知服務及實際藍牙裝置測試。
